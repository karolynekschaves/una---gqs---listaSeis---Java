# Exemplo Simples em Java

Este projeto contém um exemplo básico e direto de código em Java, ideal para iniciantes ou para testar a configuração do ambiente de desenvolvimento Java (JDK).

---

## 📌 Funcionalidades

- Exibe uma mensagem de boas-vindas no console ("Olá, Mundo!").
- Executa a operação simples de adição entre dois números inteiros.
- Imprime o resultado do cálculo no terminal.

---

## 🛠️ Pré-requisitos

Para executar este código, você precisará ter o **JDK (Java Development Kit)** instalado em sua máquina.

Para verificar se o Java está instalado, rode no terminal:

```bash
java -version
javac -version
